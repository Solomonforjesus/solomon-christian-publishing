SOLOMON READER — FINGERPRINT OF REALITY
Production branch foundation

Purpose
This directory contains the reusable Solomon Reader engine for Fingerprint of Reality. It is intentionally isolated from the live main branch until full manuscript ingestion and QA are complete.

Implemented
- Semantic book manifest with 27 internal content units
- Clean public TOC behavior
- Previous/next section navigation
- Reading-location persistence with localStorage
- Automatic return to prior section/position
- Adjustable font size
- Light/dark reading modes
- Reading progress indicator
- Section-title search
- Responsive desktop/tablet/mobile layout
- Traditional first-line paragraph indentation
- Clean front-matter treatment
- No print page numbers or Word pagination artifacts
- ISBN intentionally left null until a distributable edition is deliberately assigned one

Publication safeguard
The authoritative Word master remains untouched. Missing content files render an explicit not-public-ready notice instead of guessed text. Full manuscript content must be ingested verbatim from the authoritative master before this branch is eligible for merge to main.
